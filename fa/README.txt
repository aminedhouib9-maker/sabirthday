SAFA — BIRTHDAY WEBSITE

Open index.html in Chrome, Edge, or another modern browser.
To add Safa's photo, click “Add her photo” in the cover section.
To hear the birthday melody, tap “Play Happy Birthday”. Browsers require a click before sound can play.
The “22” section contains 22 wishes that open when the button is tapped.

To publish on Vercel: create a new project, upload this folder (or connect a Git repository), and deploy it as a static site. No build command is required.
